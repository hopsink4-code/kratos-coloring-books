# ComfyUI Prompts

Tested prompts for cute/comfy coloring book pages.

## Template

```
POSITIVE: [subject], coloring book page, line art, black and white, clean outlines, simple design, white background, high resolution, printable, cute, comfy, cozy
NEGATIVE: color, shading, gradient, shadows, watermark, text, signature, noise, blur, messy, complex background, grayscale, photorealistic, 3D
```

## Subjects to Test

- [ ] Cute animals (cats, dogs, bunnies, bears)
- [ ] Cozy scenes (reading nook, coffee shop, garden)
- [ ] Nature patterns (flowers, leaves, mushrooms)
- [ ] Fantasy (cottage, fairy, stars, moon)
- [ ] Seasonal (Christmas, Halloween, spring)

